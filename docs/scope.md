# Scope and Authorized Use

Project ini hanya untuk:

- Lab
- Staging internal
- Target dengan izin
- Website milik sendiri

Aktivitas yang diizinkan:

- Recon ringan
- Fingerprint teknologi
- Crawling endpoint
- Passive analysis
- Security header analysis
- Request/response analysis
- Manual login/register via browser
- Analisis HTTP history dari Burp/HAR
- Deteksi potensi IDOR/BOLA
- Deteksi potensi BFLA
- Deteksi potensi business logic flaw
- Deteksi potensi authentication flaw
- OWASP Top 10 mapping
- API Top 10 mapping
- CVE correlation berbasis fingerprint pada versi berikutnya

Aktivitas yang tidak diizinkan:

- Menyerang target tanpa izin
- DoS/flooding
- Brute force credential
- Upload shell
- Destructive exploit
- Dump database
- Data exfiltration
- Persistence
- Scanning target di luar allowlist
