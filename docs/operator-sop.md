# Operator SOP

Use AI Security Analyst for authorized-only internal and pre-production assessment work.

- Confirm written authorization and scope before any safe-live run.
- Do not use the project for exploit activity.
- Do not run brute force, DoS, fuzzing, or external scanner workflows.
- Do not attempt credential theft, auth bypass, persistence, malware, or shell access.
- Treat all findings as potential until manual validation is complete.
- Keep reports, evidence, and audit logs in approved internal storage.
- Remove or redact sensitive values before sharing any artifact.
