# Pre-Live Safety Checklist

- Approved assessment is present.
- Target passes scope validation.
- `allow_network` is explicit.
- `confirm_safe_live` is explicit.
- Audit log path is configured.
- Budget and rate limit are set to conservative values.
- Timeout is set to a bounded value.
- Kill switch remains available through the safe execution engine.
- No exploit, brute force, DoS, fuzzing, or external scanner activity is planned.
