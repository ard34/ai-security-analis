Methodology

This assessment uses Black Box Web/API Security Testing. The agent does not use source code, database access, backend configuration, server internals, or internal logs.

Data sources:

  • Recon results
  • Security headers
  • Technology fingerprint
  • Endpoint crawling
  • Burp/HAR traffic
  • Request/response behavior

Testing Limitations

  • No source code access
  • No database access
  • No server configuration access
  • No internal logs
  • Findings require manual validation

Evidence Handling

  • Sensitive values are masked
  • Cookies, tokens, and passwords are not stored in cleartext
  • External dependencies are not scanned
